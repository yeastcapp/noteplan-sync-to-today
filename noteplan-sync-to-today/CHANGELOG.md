# Changelog

## 1.3.0
- Default placement is Top. Choices ordered Top, Bottom, Under heading, Above heading.
- Heading name is optional and only used by the heading options.
- Plugin description explains setup and keyboard shortcut.

## 1.2.0
- Added Under heading and Above heading placement, with a heading name setting.

## 1.1.0
- Added a setting to put the copy at the top or bottom of today's note.

## 1.0.0
- `/st` appends a synced copy of the current task to the end of today's note.
